# Shelem (شلم) — Game Rules

Shelem은 이란의 전통 트릭-테이킹 카드 게임으로, 4명이 두 팀으로 나뉘어 플레이합니다.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 인원 | 4명 (2인 × 2팀) |
| 덱 | 표준 52장 |
| 승리 조건 | 누적 점수 660점 이상 |
| 진행 방향 | 반시계 방향 |

**팀 구성** — 마주 앉은 두 사람이 한 팀입니다.

```
        Player 1 (North)
            |
Player 2 --+-- Player 4    Team B = Player 2 + Player 4
 (West)     |   (East)
        Player 3 (South)

Team A = Player 1 (North) + Player 3 (South)
```

---

## 카드 점수

| 카드 | 점수 |
|------|------|
| A (에이스) | 11점 |
| Q (퀸) | 10점 |
| 10 | 5점 |
| K / J / 9 ~ 2 | 0점 |

- **카드 점수 합계**: 104점 (A×4×11 + Q×4×10 + 10×4×5)
- **트릭 점수**: 트릭 1개당 5점 × 13트릭 = 65점
- **한 핸드 총점**: **169점**

---

## 게임 흐름

```
딜 → 비딩 → 자민 교환 → 트럼프 선언 → 플레이 → 채점
 └── (전원 패스 시) 재딜 ──┘
```

---

## 1단계: 딜 (Deal)

1. 52장을 섞고, 딜러 왼쪽 플레이어가 컷.
2. 반시계 방향으로, 딜러 오른쪽부터 4장씩 나눠 각자 **12장**.
3. 남은 **4장**을 테이블 중앙에 뒤집어 놓습니다. 이를 **자민 (زمین, Zamin)** 이라 합니다.
4. 딜러는 매 핸드 반시계 방향으로 교체됩니다.

---

## 2단계: 비딩 (Bidding)

### 규칙

- 딜러 오른쪽 플레이어부터 시작, 반시계 방향 진행.
- 비드는 **자기 팀이 획득할 최소 점수**를 선언하는 것.
- 최소 비드: **100점**, 5점 단위 증가, 최대 **165점**.
- 각 플레이어는 현재 최고 비드보다 **높은 비드**를 하거나 **패스**.
- 패스한 플레이어는 재입찰 불가.
- 최고 비드 이후 **3명 연속 패스**하면 비딩 종료.
- **4명 모두 패스**하면 핸드 무효, 다음 딜러가 재딜.

### 결과

- 최고 비드를 한 플레이어가 **Hâkem (حاکم, 선언자)** 이 됩니다.
- Hâkem과 그 파트너가 **선언팀**, 나머지 둘이 **수비팀**.

---

## 3단계: 자민 교환 (Zamin Exchange)

1. Hâkem이 자민 4장을 모두 손에 들어 **16장** 보유.
2. 그 중 **4장을 비공개로 버립니다** (상대방에게 노출 안 됨).
3. 버린 4장은:
   - 선언팀의 **첫 번째 트릭으로 간주** (+5 트릭 점수)
   - A, Q, 10이 포함된 경우 해당 **카드 점수도 선언팀에 귀속**

---

## 4단계: 트럼프 선언 (Trump Declaration)

Hâkem이 플레이 모드를 선택합니다:

| 모드 | 설명 |
|------|------|
| **Normal** | Hâkem이 첫 카드를 내면, 그 카드의 무늬가 **트럼프** 확정. 표준 A>K>Q>J>10…2 서열. |
| **Nares (نارِس)** | 서열 **역전**: 2가 최고, A가 최하. 트럼프 없음. |
| **Ace-Nares** | 에이스가 여전히 최고, 그 다음 A>2>3>…>K 순. 트럼프 없음. |
| **Sarres (سارِس)** | 표준 A-high 서열이지만 트럼프 없음. |

Normal 모드에서는 Hâkem이 첫 카드를 내는 순간 트럼프가 공개됩니다.

---

## 5단계: 플레이 (Play)

### 트릭 진행

- 한 트릭 = 4명이 각각 1장씩 냄 (반시계 방향).
- 핸드당 총 12트릭 (자민 포함 시 13).
- Hâkem이 항상 첫 트릭을 리드.

### 머스트-팔로우 규칙

1. 리더는 어떤 카드든 낼 수 있음.
2. 이후 플레이어는 **리드된 무늬와 같은 카드**가 있으면 반드시 같은 무늬로 내야 함.
3. 해당 무늬가 없으면 **어떤 카드든** 낼 수 있음 (트럼프 포함).

### 트릭 승자 결정

| 상황 | 승자 |
|------|------|
| 트럼프 카드가 1장 이상 나온 경우 | 가장 높은 트럼프 카드 |
| 트럼프가 없는 경우 | 리드 무늬 중 가장 높은 카드 |

트릭 승자가 다음 트릭을 리드합니다.

---

### 플레이 예시

> **상황**: 트럼프 = ♠(스페이드), Hâkem = Player 0 (선언팀: 0·2 / 수비팀: 1·3)

#### 예시 1 — 머스트-팔로우 (모두 리드 수트 보유)

```
Player 0 (Hâkem): ♥7  ← 리드. 리드 수트 = 하트
Player 1:         ♥K  ← 하트 있음 → 반드시 하트로
Player 2:         ♥3  ← 하트 있음 → 반드시 하트로
Player 3:         ♥J  ← 하트 있음 → 반드시 하트로

트럼프 없음 → 리드 수트 중 최고: ♥K
→ Player 1 승리, 다음 트릭을 리드
```

#### 예시 2 — 리드 수트 없어서 트럼프 투입

```
Player 1 (리더): ♦A  ← 리드. 리드 수트 = 다이아몬드
Player 2:        ♦9  ← 다이아몬드 있음 → 팔로우
Player 3:        ♠5  ← 다이아몬드 없음 → 트럼프(♠) 투입
Player 0:        ♦Q  ← 다이아몬드 있음 → 팔로우

트럼프(♠) 나옴 → 가장 높은 트럼프: ♠5 (유일)
→ Player 3 승리 (♦A보다 낮은 ♠5가 이김)
```

#### 예시 3 — 여러 장의 트럼프가 나온 경우

```
Player 3 (리더): ♣8  ← 리드. 리드 수트 = 클럽
Player 0:        ♠J  ← 클럽 없음 → 트럼프 투입
Player 1:        ♣2  ← 클럽 있음 → 팔로우
Player 2:        ♠A  ← 클럽 없음 → 더 높은 트럼프 투입

트럼프 2장(♠J, ♠A) → 더 높은 트럼프: ♠A
→ Player 2 승리
```

#### 예시 4 — 리드 수트도 트럼프도 아닌 카드는 이길 수 없음

```
Player 2 (리더): ♥Q  ← 리드. 리드 수트 = 하트
Player 3:        ♦A  ← 하트 없음 → 다이아몬드 버림 (이길 수 없음)
Player 0:        ♥5  ← 하트 있음 → 팔로우
Player 1:        ♥K  ← 하트 있음 → 팔로우

트럼프 없음 → 리드 수트(♥) 중 최고: ♥K
→ Player 1 승리 (♦A는 이길 수 없음)
```

## 6단계: 채점 (Scoring)

### 한 핸드 득점 계산

```
팀 점수 = 획득한 트릭들의 카드 점수 합
        + 트릭 수 × 5
        + (선언팀만) 자민 카드 점수
        + (선언팀만) 자민 트릭 점수 5점
```

### 핸드 결과

**선언팀이 비드 이상 획득 → Win**
```
선언팀 점수 += 선언팀 득점
수비팀 점수 += 수비팀 득점
```

**선언팀이 비드 미달 → Fail**

| 조건 | 선언팀 | 수비팀 |
|------|--------|--------|
| 선언팀 득점 ≥ 수비팀 득점 | **-bid** | +수비팀 득점 |
| 선언팀 득점 < 수비팀 득점 ("더블") | **-(2 × bid)** | +수비팀 득점 |

**셸렘 (Shelem) — 모든 트릭 획득 시**
```
선언팀 점수 += 250 (셸렘 보너스)
수비팀 점수 += 0
```

### 게임 종료

- 핸드 종료 시 누적 점수가 **660점 이상**인 팀이 승리.
- 같은 핸드에 양 팀이 모두 660점 도달 시, 더 높은 팀 승리.
- 두 팀이 동점이면 다음 핸드 계속.
- **음수 점수 가능** — 연속 실패 시 점수가 마이너스가 될 수 있습니다.

---

### 채점 예시

> **공통 상황**: 선언팀 = Player 0·2, 수비팀 = Player 1·3, 비드 = 100

#### 득점 계산 방법

한 핸드가 끝나면 각 팀의 득점을 다음과 같이 계산합니다.

```
선언팀 득점 = (가져간 트릭들의 카드 점수 합)
            + (가져간 트릭 수 × 5)
            + (자민에 있던 카드 점수)
            + 5  ← 자민 트릭 점수 (항상 선언팀 귀속)

수비팀 득점 = (가져간 트릭들의 카드 점수 합)
            + (가져간 트릭 수 × 5)
```

**예시 계산:**
```
선언팀이 가져간 트릭: 8트릭
  → 카드 점수: ♥A(11) + ♠Q(10) + ♦10(5) + 나머지(0) = 26점
  → 트릭 점수: 8 × 5 = 40점
자민 카드: ♣10(5) + ♥2(0) + ♠3(0) + ♦4(0) = 5점
자민 트릭: +5점

선언팀 득점 = 26 + 40 + 5 + 5 = 76점   ← 비드(100) 미달
수비팀 득점 = 169 - 76 = 93점
```

---

#### 예시 1 — Win (비드 달성)

```
비드: 100
선언팀 득점: 110점  (비드 이상)
수비팀 득점:  59점

결과:
  선언팀 누적 점수 += 110
  수비팀 누적 점수 +=  59
```

선언팀이 목표를 달성하면 양 팀 모두 실제 득점을 그대로 받습니다.

#### 예시 2 — Fail (비드 미달, 선언팀 ≥ 수비팀)

```
비드: 100
선언팀 득점:  80점  (비드 100 미달)
수비팀 득점:  75점  ← 수비팀보다는 많음

조건: 선언팀(80) ≥ 수비팀(75) → plain fail
결과:
  선언팀 누적 점수 -= 100  (= 1 × bid)
  수비팀 누적 점수 +=  75
```

비드를 못 채웠지만 수비팀보다 더 많이 가져갔으면 페널티 한 배(-bid).

#### 예시 3 — Double (비드 미달, 선언팀 < 수비팀)

```
비드: 100
선언팀 득점:  60점  (비드 100 미달)
수비팀 득점: 105점  ← 수비팀이 더 많음

조건: 선언팀(60) < 수비팀(105) → double fail
결과:
  선언팀 누적 점수 -= 200  (= 2 × bid)
  수비팀 누적 점수 += 105
```

비드 미달인데 수비팀보다 적게 가져갔으면 페널티 두 배(-2×bid).

#### 예시 4 — Shelem (자민 포함 13트릭 전부 획득)

```
비드: 100
선언팀이 자민 포함 13트릭 전부 획득
수비팀 득점: 0점

결과:
  선언팀 누적 점수 += 250  (셸렘 보너스 고정)
  수비팀 누적 점수 +=   0
```

비드 값, 실제 득점 계산 모두 무시하고 보너스 250점이 고정으로 주어집니다.  
비드가 100이든 165이든 Shelem이면 항상 +250.

## 변형 규칙 (Variants)

### Ace-15 변형

- 에이스가 10점 대신 **15점**.
- 한 핸드 총점 = 185점.
- 최대 비드 = 185.
- 설정 파일: `configs/ace15.yaml`

### K/Q/J 점수 변형

- K=4점, Q=3점, J=2점 추가.
- 설정 파일: `configs/kqj_variant.yaml`

### 3인 셸렘

- 클럽 2를 제거 (51장).
- 각자 15장, 자민 6장.
- 최소 비드 95, 셸렘 보너스 350, 게임 임계값 650.
- 설정 파일: `configs/three_player.yaml`

## 환경 구현 매핑

게임 룰이 이 환경에서 어떻게 구현되는지 요약입니다.

| 게임 개념 | 환경 구현 |
|-----------|-----------|
| 비드 | action 53–69 (`bid_to_action(value, cfg)`) |
| 패스 | action 52 (`ACTION_PASS`) |
| 자민 버리기 | action 0–51 (카드 인덱스), 4회 연속 |
| 트럼프/모드 선언 | action 70–73 (`ACTION_MODE_OFFSET + PlayMode`) |
| 카드 내기 | action 0–51 (카드 인덱스) |
| 머스트-팔로우 | `compute_action_mask()` 가 자동 적용 |
| 채점 | `compute_hand_result()` in `shelem/game/scoring.py` |
